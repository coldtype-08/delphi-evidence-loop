한 줄

현장 면담의 약물 신호를 공개 근거(PubMed·ClinicalTrials.gov·openFDA·CMS)로 교차검증하고, 사람이 서명한 뒤에만 다음 행동으로 잇는 폐쇄 루프. 모델은 고르고 인용하고, 숫자는 코드가 세고, 관문은 사람이 지킵니다.

실행

uv sync → .env에 NVIDIA_API_KEY(build.nvidia.com, 무료) → bash scripts/demo.sh. 공개 API 응답과 모델 응답이 저장소에 캐시돼 있어 키 없이도 같은 결과가 즉시 재생됩니다.

NVIDIA 스택

  • Nemotron 3 Ultra (nvidia/nemotron-3-ultra-550b-a55b) — NIM OpenAI 호환 API. 추출·근거 판독·심의 전 과정, 한국어. 강제 함수 호출로 JSON 스키마 출력, 심의 단계만 reasoning 모드.
  • Agent Skills 규격의 evidence-loop 스킬 — 호환 에이전트에서 이 루프를 도구로 호출.
  • OpenShell / NemoClaw — deny-by-default 정책용 허용 호스트 5개 명세 (sandbox/EGRESS.md).

데이터

모든 면담 기록은 합성(가상 의료진 12인)입니다. 약은 메트포르민 — 특허 만료, 특정 회사 소유 아님, 공개 근거 최다.
